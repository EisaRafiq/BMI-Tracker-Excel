# BMI Tracker Excel

## Overview

This tracker calculates a person's change in weight, BMI and BMI category over a 10-week period.

## Features

- Calculates BMI according to the height and weight entered
- Tracks changes in weight over a 10-week period
- Tracks changes in BMI over a 10-week period
- Displays BMI categories
- Simple user interface
- Colour-coded
- Uses Excel formulas for automatic calculations

## Skills Demonstrated

- Problem solving
- Data entry and organisation
- Using Excel formulas
- Creating a clear and user-friendly spreadsheet
- Organising information over a set period of time
- Following a project from an idea to a finished result

I created this project to further develop my Excel and data-handling skills while creating something that can help people monitor changes in their weight and BMI over time.
